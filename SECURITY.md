# Security policy

Report a vulnerability in the SolidWorks MCP installer, the host, or these published skills through a private security advisory on this GitHub repository.

Please include the release version, the SHA-256 of the installer you ran, and enough detail to reproduce the issue. Do not open a public issue for an unfixed vulnerability.

The server source is not in this repository. An advisory here is still the right place to report a problem in a published build.
