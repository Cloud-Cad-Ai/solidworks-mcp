# Companion skills

These folders are copied from the SolidWorks MCP product when the setup is built. Edit them there. Do not edit them in this repository.

| Skill | Description |
|---|---|
| `cad-design-orchestrator` | Orchestrate multi-phase engineering design jobs (requirements, calculations, CAD parts, assembly, drawings, reports) by delegating to right-sized subagents run in sequence or in parallel by dependency, with quality checks that pinpoint what's wrong, keeping token use low without losing accuracy. Use whenever a user asks to design a machine, gearbox, fixture, mechanism or product end-to-end, to build several CAD parts plus an assembly, or to produce design docs with CAD, even if they don't mention subagents. |
| `concept-machine-visualizer` | Turn a mechanical machine spec or problem statement into 2â€“3 concept alternatives, a weighted selection, back-of-envelope sizing (motors, gearing, actuators, bearings, frames), and a dimensioned concept sheet (third-angle views + isometric + BOM) backed by a machine-readable concept.json for downstream CAD/design agents. Use this whenever someone needs a machine, mechanism, fixture, rig, robot, conveyor, press, gripper, test stand, or any mechanical-design concept conceptualised, sketched, laid out or visualised from requirements â€” even if they only say "come up with a design forâ€¦", "what would this machine look like", "concept for a device thatâ€¦", or hand over a spec sheet. Not for detailed drawings of an existing CAD model or for pure data charts. |
| `mechanical-reasoner` | Engineering reasoning loop for mechanical and machine design, from requirements through calculation, CAD and validation. Use whenever the user asks to size, select or check a mechanical part or drive (shaft, beam, bracket, frame, plate, pulley, bearing, gearmotor, belt, conveyor, fixture, bolted joint), choose a material, section or architecture, asks \"will this hold\", \"what motor do I need\", \"how thick should this be\", wants a part or assembly modeled in SolidWorks or other CAD from engineering requirements, or reports a failed check, FEA result, interference, slip, overheating, deflection or breakage that needs diagnosing. Use it even when the request sounds like a quick sizing question. |
| `set-material` | Assign a library material (steel, aluminum, etc.) to the open SolidWorks part's active configuration through the SolidWorks API tools. Use this whenever the user asks to set, change, apply or assign a material on a part, including casual phrasing like \"make this part steel\" or \"set plain steel\", even if they don't say \"material\". |
| `solidworks` | Drive the open SolidWorks model with named tools. Lengths are meters. Angles are radians. |
| `solidworks-api` | Look up a SolidWorks API member. Does not search the open model. |
| `solidworks-assembly-build` | Model parts and build SolidWorks assemblies from a design state or spec: frames, generated equations file, sub-assemblies in dependency order, static and moving mate schemes, and per-level checks. Use for any multi-part SolidWorks build, including moving mechanisms. |
| `solidworks-bridge-tool-selection` | Use before any SolidWorks MCP modeling or assembly work to pick the tool or API call that actually works through this bridge and avoid known failures. |
| `solidworks-macro-fallback` | Use when a SolidWorks API call through the MCP bridge needs a ref/out parameter or a COM object argument (limit mates, gear mates, AddMate5, ModifyDefinition), and only after the user has agreed to macros being used. |
| `solidworks-motion-mates` | Use when a SolidWorks assembly must move (cylinder extend/retract, slide, stroke) so the user can drag it within limits, instead of positioning everything with fixed distance equations. |
| `solidworks-parametric-assembly-build` | Use when building a SolidWorks assembly from a spec that should be driven by one global-variables file, especially when sizes are placeholders pending inputs. |
| `solidworks-procedure` | Create a procedure skill from this conversation. Use when the user says "Create a procedure skill named NAME from this conversation. |
